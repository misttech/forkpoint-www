# forkpoint-www

The website for Forkpoint, published to GitHub Pages at
[forkpoint.mist-os.com](https://forkpoint.mist-os.com/).

## No build step

The site is HTML, CSS, and a small amount of JavaScript, served exactly as
written. There is no static site generator, bundler, or npm dependency.

```sh
make serve     # http://localhost:8000
```

## Domain

`CNAME` declares `forkpoint.mist-os.com`. Until DNS and GitHub Pages HTTPS are
configured, the github.io URL is
`https://misttech.github.io/forkpoint-www/`.
